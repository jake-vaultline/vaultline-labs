Install from the terminal

curl -fsSL https://vaultline.io/ingest/install.sh | bash

Downloads the notarized build, checks its SHA-256 before opening it, and copies it to Applications. No sudo, nothing written anywhere else. Prefer the button above if you'd rather not pipe a script — it installs exactly the same app.

What it does

Copies to several places at once

The card is read once and written to every destination from that same read. Two backups shouldn't cost three passes.

Verifies by reading back

A file counts as done only after it's been read off the destination and its checksum matched. Not when the write returned.

xxHash64 by default

The same checksum the offload world already uses. Fast enough that verifying isn't the reason anyone turns verifying off.

Writes ASC MHL

A standard manifest, not a proprietary one, so a facility or an archivist can read it without your software.

Learns your naming convention

Point it at old work. It reads the real names, finds the pattern, and tells you how consistently you've actually followed it.

Configured around your team

Vaultline configures your ingest form, naming, destination layout, folder tree and real Premiere template for free.

What it will never do

An ingest tool that loses footage isn't worth using.

  • Never moves. Your card is read and left exactly as it was.
  • Never deletes. There is no delete anywhere in the app.
  • Never overwrites. A name collision stops and asks. There is no "overwrite" setting to accidentally leave switched on.
  • Works standalone. Ingest needs no account, Media Nexus or Relay connection. There is no upload path for footage.
  • Never phones home. No analytics, no telemetry, no update check. Settings lists every optional Drive Passport request the app makes.
